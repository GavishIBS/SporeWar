# SporeWar: RotRising

SporeWar: RotRising is a top-down shooter developed using Unreal Engine for PC. The game focuses on combat, enemy encounters, and delivering an engaging gameplay experience.

## About the Project

SporeWar: RotRising is an indie game developed by Inverted Button Studios. The project explores top-down shooter gameplay, combining game design and development to create an original gaming experience.

This repository documents the project and its development.

## Features

- Top-down shooter gameplay
- Combat-focused game design
- Developed using Unreal Engine
- Built for PC

## Built With

- Unreal Engine
- C++

## Platform

PC
